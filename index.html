학부의 서버와 시스템을
학생이 직접 관리합니다

바쿠스(Bacchus)는 서울대학교 컴퓨터공학부의 시스템 관리자 동아리입니다. GPU 서버, 실습 환경, 통합계정, 학부 홈페이지처럼 학부 구성원이 매일 사용하는 서비스를 직접 개발하고 운영합니다.

서울대학교와 관련된 사람이라면 누구나 가입할 수 있습니다.

동아리 소개 → 운영 서비스 안내 → 신입회원 모집 안내 →

무엇을 하는 곳인가요

컴퓨터 시스템을 좋아하는 사람들이 모여 세 가지 일을 합니다.

개발

학부에 필요한 서비스를 직접 만들고 관리합니다.

  • · GPU 서버 할당 서비스(SGS) 개발 및 운영
  • · 통합계정 등 학부 핵심 서비스 개발
  • · 서버 인프라 운영 및 관리

연구

실제 인프라에서 마주친 문제를 깊이 공부합니다.

  • · GPU 활용률 분석
  • · ML 시스템
  • · 시스템 연구 및 코드 최적화

교류

같은 관심사를 가진 사람들과 친목을 다집니다.

  • · 정기 네트워킹 파티
  • · 신입회원 환영회
  • · 커뮤니티 교류 활동

학부 구성원에게 제공하는 서비스

학부생과 대학원생이 공부와 연구에 집중할 수 있도록 아래 환경을 운영합니다.

GPU 서버

딥러닝 실습·연구용 고성능 GPU 서버(A100 28장, 4대)를 무료로로 제공합니다. SGS 포털

실습 서버

리눅스 실습 서버 martini, 웹 실습 서버 mimosa 등 수업 실습 환경을 운영합니다.

통합계정

하나의 계정으로 학부의 모든 서비스를 이용할 수 있는 통합계정을 발급합니다.

실습실 PC

하드웨어 실습실과 과방 PC의 소프트웨어 설치와 업데이트를 관리합니다.

웹 서비스

학부 홈페이지와 학부생 커뮤니티 SNUCSE의 운영을 관리합니다.

백업·보안

중요한 자료를 주기적으로 백업하고, 보안 문제에 대응합니다.
